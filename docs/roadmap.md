# Repository Roadmap

이 저장소는 AI / 프로그래밍 / 인터넷 기술 개인 연구소로 운영합니다.

## 1단계: 구조 안정화

- [x] 수업 원본을 `coursework/AI_Study/`로 이동
- [x] 독립 분석 프로젝트를 `projects/`로 이동
- [x] 짧은 노트북 실험을 `experiments/`로 이동
- [x] 일반 프로그래밍 학습 구조를 `programming/`으로 분리
- [x] 저장소 분석 도구를 `tools/repo_cleaner/`에 추가
- [x] 루트 README와 프로젝트 인덱스 갱신

## 2단계: 안전 점검

- [ ] 민감정보 후보를 실제 값 출력 없이 수동 점검

- [ ] 이미 추적 중인 캐시/가상환경/모델 파일 목록 확인
- [ ] 대형 파일의 Git LFS 또는 외부 보관 기준 결정
