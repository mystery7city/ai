# 03 TypeScript

## 목적

JavaScript 코드에 타입을 적용해 더 안전한 웹앱 구조를 익힌다.

## 배울 개념

- type, interface
- union, generic
- narrowing
- module
- API response type
- tsconfig 기본

## 추천 미니 프로젝트

- typed todo model
- API 응답 타입 정의
- 작은 utility 함수 모음

## 완료 기준

기본 타입을 정의하고 API 데이터 구조를 TypeScript로 표현할 수 있다.
