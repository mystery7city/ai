# 05 Web Frontend

## 목적

프론트엔드 애플리케이션의 구조와 API 연동 방식을 익힌다.

## 배울 개념

- component
- state
- props
- routing
- form
- API 호출
- loading/error state

## 추천 미니 프로젝트

- REST API 목록/상세 화면
- 검색 가능한 데이터 테이블
- 간단한 관리자 페이지

## 완료 기준

백엔드 API와 연결된 화면을 만들고 loading/error/empty 상태를 처리할 수 있다.
