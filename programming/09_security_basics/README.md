# 09 Security Basics

## 목적

웹앱과 API를 만들 때 필요한 보안 기본 원칙을 익힌다.

## 배울 개념

- password hashing
- session
- cookie
- JWT
- OAuth
- CSRF
- XSS
- SQL injection
- environment variables
- secret management

## 추천 미니 프로젝트

- 안전한 로그인 흐름 설계
- `.env` 사용 규칙 문서
- XSS/SQL injection 방어 예시 정리

## 완료 기준

비밀번호를 평문 저장하지 않는 이유와 secret을 코드에 직접 쓰면 안 되는 이유를 설명할 수 있다.
