# Programming Roadmap

인터넷 프로그램과 일반 개발 기술을 단계적으로 배우기 위한 로드맵이다.

## 1. Python 기초와 자동화

- 배울 개념: 변수, 함수, 조건문, 반복문, 파일 입출력, pathlib, argparse, JSON, 예외 처리
- 만들 미니 프로젝트: 파일 정리 리포트 생성기
- 추천 폴더 위치: `01_python/`, `12_automation/`
- 완료 기준: 명령어로 실행 가능한 Python 스크립트를 만들고 README에 사용법을 적는다.

## 2. HTML/CSS/JavaScript 기초

- 배울 개념: HTML 문서 구조, CSS 선택자, flex/grid, JavaScript 문법, DOM, event, fetch
- 만들 미니 프로젝트: 할 일 목록 웹페이지
- 추천 폴더 위치: `04_html_css/`, `02_javascript/`
- 완료 기준: 브라우저에서 동작하는 정적 페이지를 만들고 사용자 입력을 처리한다.

## 3. HTTP와 네트워크 기본

- 배울 개념: HTTP method, URL, DNS, IP, port, request/response, status code, client/server
- 만들 미니 프로젝트: HTTP 요청/응답 관찰 노트
- 추천 폴더 위치: `08_network/`
- 완료 기준: GET/POST 요청의 차이를 설명하고 status code 예시를 정리한다.

## 4. REST API와 백엔드 서버

- 배울 개념: REST API, routing, request body, response body, JSON, middleware, validation
- 만들 미니 프로젝트: REST API Practice
- 추천 폴더 위치: `06_backend/rest_api_practice/`
- 완료 기준: CRUD API를 만들고 API 문서와 실행 방법을 README에 기록한다.

## 5. 데이터베이스와 SQL

- 배울 개념: SQLite, PostgreSQL, table, schema, query, index, transaction, migration, ORM
- 만들 미니 프로젝트: SQLite 기반 아이템 저장소
- 추천 폴더 위치: `07_database/`
- 완료 기준: 테이블 생성, CRUD query, 간단한 migration 흐름을 설명한다.

## 6. 프론트엔드 구조

- 배울 개념: component, state, props, routing, form, API 연동, error/loading state
- 만들 미니 프로젝트: REST API를 호출하는 프론트엔드 화면
- 추천 폴더 위치: `05_web_frontend/`
- 완료 기준: 백엔드 API에서 데이터를 가져와 목록/상세/입력 UI를 만든다.

## 7. 인증/보안 기초

- 배울 개념: password hashing, session, cookie, JWT, OAuth, CSRF, XSS, SQL injection, environment variables
- 만들 미니 프로젝트: 로그인 흐름 설계 문서
- 추천 폴더 위치: `09_security_basics/`
- 완료 기준: 안전한 비밀번호 저장과 환경변수 관리 원칙을 설명한다.

## 8. 테스트와 디버깅

- 배울 개념: unit test, integration test, fixture, mocking, debugging, logging
- 만들 미니 프로젝트: REST API 테스트 추가
- 추천 폴더 위치: `15_testing/`, `06_backend/rest_api_practice/`
- 완료 기준: 주요 API 동작을 자동 테스트로 검증한다.

## 9. Docker와 DevOps 기초

- 배울 개념: Docker, Dockerfile, docker-compose, environment variables, CI/CD, GitHub Actions, deployment, monitoring
- 만들 미니 프로젝트: 로컬 Docker 실행 환경
- 추천 폴더 위치: `10_devops/`
- 완료 기준: 앱을 Docker로 실행하고 환경변수와 로그 확인 방법을 정리한다.

## 10. AI 기능을 웹앱에 연결하기

- 배울 개념: API wrapper, prompt input, async request, error handling, rate limit, secret management
- 만들 미니 프로젝트: AI 요약 기능이 붙은 웹 API
- 추천 폴더 위치: `projects/` 또는 `mini_projects/`
- 완료 기준: 일반 웹앱 구조 위에 AI 기능을 안전하게 연결하고 키를 코드에 직접 쓰지 않는다.
